# Currency Converter

A responsive currency converter built with HTML, CSS, and JavaScript by Shaheer Rana.

## Features
- Exchange rates for 166 currencies from ExchangeRate-API
- USD to PKR defaults and a currency swap control
- Dark and light themes
- Responsive layout

## Run locally
Open `index.html` in a browser. An internet connection is required for exchange rates and icons.

Rates are provided by [ExchangeRate-API](https://www.exchangerate-api.com/).
